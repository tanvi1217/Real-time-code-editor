# Real-time-code-editor
Real-Time Code Editor is a collaborative web application that allows multiple users to write and edit code simultaneously with instant synchronization. Changes made by one user are reflected in real time for all participants, enabling efficient collaboration, pair programming, and online coding sessions.
# 🧑‍💻 Real-Time Code Editor (In Progress)

This project is a **Real-Time Code Editor** currently under development.
It aims to provide a collaborative environment where multiple users can
write and edit code simultaneously with real-time synchronization.

At this stage, the project focuses on setting up the backend server and
basic frontend structure. Core real-time collaboration features are
partially implemented and will be expanded in future updates.

## ⚙️ How to Run the Project

1.  Clone the repository:

    ``` bash
    git clone https://github.com/your-username/your-repo-name.git
    ```

2.  Navigate to the project directory:

    ``` bash
    cd your-repo-name
    ```

3.  Install dependencies:

    ``` bash
    npm install
    ```

4.  Start the server:

    ``` bash
    node server.js
    ```

5.  Open `Dashboard.html` in your browser.
